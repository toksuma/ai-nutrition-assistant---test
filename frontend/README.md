# Frontend - AI Nutrition Assistant

React + Vite + Tailwind CSS frontend for the AI Nutrition Assistant.

## Features

- Upload food images
- Display image preview
- Call backend API for analysis
- Display nutritional information

## Setup

1. Install dependencies:
```bash
npm install
```

## Running

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

## Configuration

The API endpoint is configured to call `http://localhost:8000/api/analyze`. 
Make sure the backend is running before using the application.
